## No closed form, so descend

In Week 1, setting the gradient of the squared loss to zero gave linear equations, $X\T X\theta = X\T\by$, which we could solve directly. The logistic loss is convex but has **no closed-form solution**, so we use gradient descent. The reason will be visible once we have the gradient: the probabilities inside it depend nonlinearly on β.

## The gradient, one observation at a time

<Steps>
Differentiate one observation’s loss first, then sum. Each step is short; predict it before you click.

<Step title="The sigmoid’s derivative">
$$
\sigma(z) = (1 + e^{-z})^{-1} \;\Rightarrow\; \sigma'(z) = \frac{e^{-z}}{(1 + e^{-z})^2} = \sigma(z)\big(1 - \sigma(z)\big).
$$

(Write $\frac{e^{-z}}{1 + e^{-z}} = 1 - \sigma(z)$.)
</Step>

<Step title="One observation, differentiated with respect to its score">
$$
L = -y\log p - (1 - y)\log(1 - p), \qquad p = \sigma(z).
$$

$$
\frac{\partial L}{\partial z} = \Big(-\frac yp + \frac{1 - y}{1 - p}\Big)\,p(1 - p) = -y(1 - p) + (1 - y)p = p - y.
$$

The sigmoid’s derivative cancels the denominators: what remains is just “predicted minus actual”.
</Step>

<Step title="Chain rule to the coefficients">
Since $z = \bxt\T\beta$, $\partial z/\partial\beta = \bxt$, so $\nabla_\beta L = (p - y)\,\bxt$. The intercept uses the augmented coordinate 1.
</Step>

<Step title="Average over the data">
$$
\nabla J(\beta) = \frac1m\sum_{j=1}^m (p_j - y_j)\,\bxt_j = \frac1m X\T(\bp - \by).
$$

$$
\boxed{\;\beta_{\text{new}} = \beta_{\text{old}} - \frac\alpha m X\T(\bp - \by)\;}
$$

Here $\bp$ holds the probabilities computed with the *old* β, and all components update simultaneously. Unlike Week 1’s MSE convention there is no factor 2.
</Step>
</Steps>

<Callout kind="note" title="Why no closed form">
Setting the gradient to zero gives $X\T\big(\sigma(X\beta) - \by\big) = \mathbf 0$ with σ applied entry by entry. The unknown β sits inside a nonlinear function, so this is not $X\T X\beta = X\T\by$ and cannot be solved by one matrix inverse.
</Callout>

<Callout kind="example" title="One update by hand">
Data $(x, y) = (0, 0), (1, 1)$, start at $\beta = (0, 0)\T$, so both probabilities are 0.5:

$$
X = \begin{pmatrix}1 & 0\\ 1 & 1\end{pmatrix}, \quad \bp - \by = \begin{pmatrix}0.5\\ -0.5\end{pmatrix}, \quad \nabla J = \frac12 X\T(\bp - \by) = \begin{pmatrix}0\\ -0.25\end{pmatrix}.
$$

With $\alpha = 1$, $\beta_{\text{new}} = (0, 0.25)\T$. The probabilities become 0.5 and $\sigma(0.25) \approx 0.5622$, and the average loss falls from $\log 2 \approx 0.6931$ to about 0.6345. One improving step — not convergence.
</Callout>

## What convexity does — and does not — guarantee

For one observation, $\partial^2 L/\partial z^2 = p(1 - p) \ge 0$, so the loss is convex in its score; the score is linear in β, and a convex function of a linear map is convex; averages of convex functions are convex. Hence $J$ is convex in β, and **any stationary point is a global minimiser** — gradient descent cannot be trapped in a bad local minimum: there is a single global minimum value.

<Callout kind="warning" title="Convex ≠ exactly one finite minimiser">
- **Duplicate feature columns** let you shift weight between them without changing any score: many β give the same minimum.
- **Perfectly separable data** has no finite minimiser. For $(x, y) = (-1, 0), (1, 1)$ with score $bx$, the average loss is $\log(1 + e^{-b})$, which decreases towards 0 as $b \to \infty$ but never reaches it. Regularisation (Week 1) restores a finite optimum.
</Callout>

## Strengths and weaknesses

| Pros | Cons |
| --- | --- |
| relatively easy to implement | binary classifier as stated (multiclass needs an extension) |
| easy to interpret: coefficients act on the log-odds | linear boundary — curved boundaries need feature transformations |
| fast to train, very fast to predict (a dot product and a sigmoid) | can overfit with many features (remedy: regularisation) |
| gives probabilistic predictions | correlated inputs make coefficients unstable; sensitive to outliers |

<p className="small muted">A probabilistic output is not automatically a *well-calibrated* probability, and cheap fitting does not guarantee generalisation — that is what evaluation (lessons 6–9) is for.</p>

<Callout kind="key">
Per observation the score derivative is just $p - y$, so $\nabla J = \frac1m X\T(\bp - \by)$ and gradient descent updates $\beta \leftarrow \beta - \frac\alpha m X\T(\bp - \by)$ with the old probabilities. The loss is convex, so any stationary point is global — but there is no closed form, and separable or redundant data can leave no unique finite optimum.
</Callout>
