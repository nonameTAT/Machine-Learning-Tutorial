## Why ask for more than “a number that is small for similar things”?

Any formula can produce numbers. A **metric** formalises the properties we silently assume when we say “distance”: no separation from yourself, symmetry, and no shortcuts. Algorithms that search for neighbours efficiently, and arguments about neighbourhoods, rely on these properties.

Given an instance space $\mathcal X$, a **distance metric** is a function $\mathrm{Dis}: \mathcal X \times \mathcal X \to [0, \infty)$ such that for all $x, y, z$:

| Property | Statement | Meaning |
| --- | --- | --- |
| 1. Zero at the same point | $\mathrm{Dis}(x, x) = 0$ | no separation from yourself |
| 2. Positive otherwise | $x \ne y \Rightarrow \mathrm{Dis}(x, y) > 0$ | distinct points are distinguishable |
| 3. Symmetry | $\mathrm{Dis}(x, y) = \mathrm{Dis}(y, x)$ | order does not matter |
| 4. Triangle inequality | $\mathrm{Dis}(x, z) \le \mathrm{Dis}(x, y) + \mathrm{Dis}(y, z)$ | a detour cannot be shorter |

If property 2 is weakened so that $\mathrm{Dis}(x, y) = 0$ is allowed for $x \ne y$, the function is a **pseudometric**.

## One counterexample disproves a property

The triangle inequality fails for Minkowski distances with $p < 1$. To see it, you do not need a general proof — just three points:

<Callout kind="example" title="p = ½">
$a = (0, 0)$, $b = (1, 0)$, $c = (1, 1)$. Directly,

$$
d_{1/2}(a, c) = \big(\sqrt1 + \sqrt1\big)^2 = 4,
$$

but each leg via $b$ differs in one coordinate only, so $d_{1/2}(a, b) = d_{1/2}(b, c) = 1$. Since $4 > 1 + 1$, the triangle inequality fails. The formula is symmetric and zero only at identical points — those properties alone do not make it a metric.
</Callout>

<Callout kind="example" title="Squared Euclidean distance is not a metric either">
On the real line take 0, 1, 2. The direct squared distance is $4$; the two legs total $1 + 1 = 2$. Violated. Yet squared Euclidean distance orders neighbours exactly as Euclidean distance does (lesson 11) — a function can be useful for ranking without being a metric.
</Callout>

## Pseudometrics: deliberately ignoring a difference

A pseudometric keeps symmetry and the triangle inequality but lets distinct points be at distance zero. For example,

$$
d(\bx, \bz) = |x_1 - z_1|
$$

ignores the second coordinate: $(1, 0)$ and $(1, 9)$ are different points at distance 0. This is exactly what happens when a feature’s weight is set to zero in a weighted distance — setting $z_j$ to zero eliminates that dimension altogether. If all weights are positive, weighted Euclidean distance is a metric again.

<Callout kind="note" title="“Not a norm” is not “not a metric”">
The mismatch count $d_0$ (lesson 11) is not a norm, but it *is* a metric on fixed-length vectors: for each coordinate, if $x_r \ne z_r$, then $y_r$ must differ from at least one of them, so every mismatch on the direct route is paid for on the detour.
</Callout>

<Callout kind="note" title="How to answer a metric question">
State the required property. To **prove** it, argue for arbitrary inputs — checking three convenient pairs is not a proof. To **disprove** it, give explicit points that violate it: one valid counterexample is enough.
</Callout>

<Callout kind="key">
A metric is zero only between identical points, symmetric, and obeys the triangle inequality. Minkowski $d_p$ is a metric for $p \ge 1$ but not for $p < 1$; squared Euclidean distance is not a metric (yet ranks neighbours correctly); allowing zero distance between distinct points gives a pseudometric, as when a feature’s weight is zero.
</Callout>
