## Uncertainty can remain even with the right probabilities

Suppose that for some input $x$ the *true* class probabilities are $P(c_1 \mid x) = 0.7$ and $P(c_2 \mid x) = 0.3$. Predicting $c_1$ is wrong with probability 0.3; predicting $c_2$ is wrong with probability 0.7. We should predict $c_1$, but no amount of learning can make that error 0 — inputs like this genuinely come from both classes.

What is the best performance any classifier could achieve? Define the probability of error at an input:

$$
P(\text{error} \mid x) = \begin{cases} P(c_1 \mid x) & \text{if we predict } c_2 \\ P(c_2 \mid x) & \text{if we predict } c_1, \end{cases} \qquad P(\text{error}) = \sum_x P(\text{error} \mid x)\,P(x).
$$

The rule “predict $c_1$ if $P(c_1 \mid x) > P(c_2 \mid x)$” makes each $P(\text{error} \mid x)$ as small as possible, so on average it minimises the probability of classification error. Its error is the **Bayes error**:

$$
R^*(x) = 1 - \max_c P(c \mid x), \qquad R^* = \E_X\big[1 - \max_c P(c \mid X)\big].
$$

For two classes $R^*(x) = \min\{P(c_1 \mid x), P(c_2 \mid x)\}$. For discrete inputs the expectation is a weighted sum over $x$; for continuous inputs, an integral. Bayes error concerns zero-one classification error, not an arbitrary cost-sensitive loss.

## Worked example: two input patterns

$$
R^* = 0.4 \times 0.2 + 0.6 \times 0.3 = 0.26.
$$

The best achievable expected accuracy with these features is 0.74. Averaging 0.2 and 0.3 without the weights $P(x)$ would be wrong — the patterns do not occur equally often.
</Callout>

## What more data can and cannot do

Lesson 7 averaged uncertainty about *hypotheses given finite data*. This lesson assumes the true class posterior is known and asks for the minimum attainable error using these features. Both apply the same principle: maximise the appropriate posterior under zero-one loss.

<Callout kind="note">
More representative training data can bring a learned rule closer to the Bayes rule. It cannot remove the overlap already present in the true $P(c \mid x)$ for a fixed feature set. New, informative *features* change that posterior — and can lower the Bayes error.
</Callout>

<Callout kind="key">
Even the best rule — predict the class with the largest true posterior — errs with probability $1 - \max_c P(c \mid x)$ at each input. Averaged over inputs this is the Bayes error $R^* = \E_X[1 - \max_c P(c \mid X)]$: the floor for any classifier using these features.
</Callout>
