## One binary probability per word and class

In the multivariate Bernoulli model, a document is a bit vector $z = (z_1, \dots, z_m)$ over the vocabulary, and each bit is a separate coin with its own probability $\theta_{jc} = P(X_j = 1 \mid c)$. Training:

<Steps>
<Step title="Add the bit vectors within each class">
Spam: $(2, 3, 1)$; ham: $(3, 1, 1)$ — the number of documents in each class containing a, b, c. There are 4 documents per class.
</Step>

<Step title="Smooth with two pseudo-documents">
One containing every word and one containing none, so each word gains one “present” and one “absent”:

$$
\hat\theta_{jc} = \frac{\text{documents in } c \text{ containing word } j + 1}{N_c + 2}.
$$
</Step>

<Step title="Result">
$$
\hat\theta_{\text{spam}} = \big(\tfrac36, \tfrac46, \tfrac26\big) = \big(\tfrac12, \tfrac23, \tfrac13\big), \qquad \hat\theta_{\text{ham}} = \big(\tfrac46, \tfrac26, \tfrac26\big) = \big(\tfrac23, \tfrac13, \tfrac13\big).
$$
</Step>
</Steps>

These three components need *not* sum to 1: they describe three separate binary variables. For each word, present and absent probabilities do sum to 1. For example, the presence of b is twice as likely in spam as in ham.

## Score a document using both outcomes

$$
P(z \mid c) = \prod_{j=1}^m \theta_{jc}^{\,z_j}(1 - \theta_{jc})^{1 - z_j}.
$$

The exponent selects the right factor. An absent word is still *observed to be absent*, so its factor $1 - \theta_{jc}$ cannot be dropped.

<Callout kind="example" title="Example: an email containing a and b but not c">
$z = (1, 1, 0)$:

$$
P(z \mid \text{spam}) = \tfrac12 \times \tfrac23 \times \big(1 - \tfrac13\big) = \tfrac29 \approx 0.222, \qquad P(z \mid \text{ham}) = \tfrac23 \times \tfrac13 \times \big(1 - \tfrac13\big) = \tfrac{4}{27} \approx 0.148.
$$

The likelihood ratio is $(2/9)/(4/27) = 3/2$: the ML classification is spam, and with equal priors MAP agrees, with spam posterior $3/5$.
</Callout>

With 1/3 spam and 2/3 ham the prior odds are 1/2 and the posterior odds $\tfrac32 \times \tfrac12 = \tfrac34$: MAP predicts ham. The *feature evidence* is unchanged — only the prior moved. The MAP decision is spam exactly when the prior odds exceed 2/3.

1. Reproduce the worked example: email “a b” gives 2/9 versus 4/27 and likelihood ratio 3/2. Then set P(spam) = 1/3: the decision flips to ham.
2. Change the email to “a a a b”: nothing changes — the presence vector is still (1, 1, 0).
3. Try an email with no vocabulary words (“d e”). Every factor is an absence factor, and they do not cancel between classes.
4. Turn smoothing off: the parameters become (2/4, 3/4, 1/4) and (3/4, 1/4, 1/4).
</TryThis>

<Callout kind="warning" title="Do not confuse the denominators">
Bernoulli smoothing uses the number of documents in the class plus 2. It does not use total word occurrences, and it does not add the vocabulary size.
</Callout>

<Callout kind="key">
Bernoulli Naive Bayes estimates $\theta_{jc} = (\text{docs in } c \text{ with word } j + 1)/(N_c + 2)$ and scores a bit vector with $\prod_j \theta_{jc}^{z_j}(1 - \theta_{jc})^{1 - z_j}$ — absent words count as evidence. Repetitions are invisible to it, and the prior enters only through the posterior odds.
</Callout>
