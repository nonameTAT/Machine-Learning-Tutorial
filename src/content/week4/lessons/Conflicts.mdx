## Identical inputs share a leaf

“An unpruned tree fits its training data perfectly” sounds like a law. It is not. A tree that tests only the attributes A, B and C sends every example with the same values of (A, B, C) to the same leaf, and a leaf makes one prediction. If two such examples carry different labels, at least one of them is misclassified — by *every* tree on these attributes, however deep.

Consider twelve training examples with binary attributes A, B, C and label Y, grouped by input tuple:

<ConflictLab />
</Lab>

The tuples (0, 1, 1) and (1, 1, 1) each hold one example of each label. Whatever their leaves predict, one example in each is wrong, so at least two errors are unavoidable. A tree that tests A, then B, then C gives every tuple its own leaf; labelling each leaf by majority makes exactly those two errors. So the fully grown, unpruned tree has training error **2 out of 12**, or $1/6$ — there is no attribute left to separate the conflicting pairs.

In general, if input tuple $g$ has $n_g$ examples with class counts $n_{g,1}, \dots, n_{g,k}$, the fewest errors any tree on these attributes can make is

$$
E_{\min} = \sum_g \big(n_g - \max_j n_{g,j}\big).
$$

<TryThis>
1. Add one more Y = 0 example to (0, 1, 1). The tuple still contributes one error: the majority is now 0, and the single 1 is wrong.
2. Make (1, 1, 1) hold two of each label: it alone now forces two errors.
3. Remove the conflicts and E_min drops to 0 — only then can an unpruned tree be perfect.
</TryThis>

<Callout kind="warning" title="E_min is a floor, not a forecast">
The formula counts disagreement *within identical inputs*. A tree that stops early, or merges tuples into the same leaf, can make more errors than $E_{\min}$. And conflicting labels are information: they show that A, B and C do not determine Y — there is noise, or a missing feature.
</Callout>

## The worst case with k classes

How bad can a tree’s training error be, for *any* dataset with $k$ classes? Look at one leaf at a time.

<Steps>
<Step title="One leaf">
A leaf with $m$ examples spread over $k$ classes has a largest class with at least $m/k$ examples (they cannot all be below the average).
</Step>

<Step title="Errors at that leaf">
The leaf predicts that majority class, so it misclassifies at most $m - m/k = m(1 - 1/k)$ examples.
</Step>

<Step title="Add up the leaves">
$$
\text{training errors} \le \sum_{\text{leaves}} m_\ell\Big(1 - \frac1k\Big) = n\Big(1 - \frac1k\Big) \;\Rightarrow\; \text{error fraction} \le 1 - \frac1k.
$$
</Step>

<Step title="The bound is attained">
Give all examples exactly the same input values and spread the labels evenly over the $k$ classes. No test can separate them; the single leaf gets $1/k$ of them right. For $k = 3$ the error is $2/3$; for $k = 2$, $1/2$.
</Step>
</Steps>

<Lab title="All inputs identical" purpose="Every example has the same attribute values, so all share one leaf. The leaf predicts the largest class.">
<WorstCaseLab />
</Lab>

For a fixed number of examples $n$, the exact worst case is $(n - \lceil n/k\rceil)/n$, reached by making the class counts as equal as integers allow; it equals $1 - 1/k$ when $k$ divides $n$.

<Callout kind="note" title="State the assumption">
The bound assumes every leaf predicts its majority class, with all errors costing the same. It is not a bound on a deliberately perverse classifier, and the word “unpruned” does nothing to remove conflicting labels.
</Callout>

<Quiz id="q3">
When does growing a tree without limit guarantee zero training error?

<Option>Always <Why>Conflicting labels on identical inputs make it impossible.</Why></Option>
<Option correct>Exactly when no two training examples with identical inputs have different labels <Why>Then each distinct input can get its own correct leaf.</Why></Option>

<Callout kind="key">
A tree can only separate examples whose inputs differ. Identical inputs with different labels force $E_{\min} = \sum_g (n_g - \max_j n_{g,j})$ errors on any tree — 2 of 12 in the classic table. With k classes and majority leaves, training error can never exceed $1 - 1/k$, and that bound is reached when all inputs coincide and the labels are spread evenly.
</Callout>
